# Quint

電卓・天気・タイマー・習慣・カメラを1つにまとめた PWA。黒基調・粒子テクスチャ・立体数字のミニマルな UI。

## 使い方

```sh
python3 -m http.server 8000   # http://localhost:8000
```

iPhone では HTTPS で配信したページを Safari で開き、「共有 → ホーム画面に追加」でアプリとして使えます（カメラは HTTPS 必須）。

| アプリ | 操作 |
| --- | --- |
| 電卓 | `12+25%` = 15 のようなパーセント計算。表示部を横スワイプで1文字削除。右上で履歴 |
| 天気 | Open-Meteo（APIキー不要）。現在地または検索した都市。24時間・7日間・詳細 |
| タイマー | 上下スワイプで分を設定、タップで開始/一時停止、長押しでリセット |
| 習慣 | ＋で追加、景色をタップで今日を記録。記録日数で60段階の旅が進む |
| カメラ | 4種のフィルター、前後切替、写真は端末内(IndexedDB)に保存 |

データはすべて端末のブラウザ内（localStorage / IndexedDB）に保存されます。
