# Quint

電卓・天気・タイマー・習慣・カメラを1つにまとめた PWA。黒基調・粒子テクスチャ・立体数字のミニマルな UI。

## 使い方

```sh
python3 -m http.server 8000   # http://localhost:8000
```

iPhone では HTTPS で配信したページを Safari で開き、「共有 → ホーム画面に追加」でアプリとして使えます（カメラは HTTPS 必須）。

| アプリ | 操作 |
| --- | --- |
| 下のタブバー | 電卓・天気・タイマー・習慣・カメラを切り替え（Jam と同じ浮かぶガラスのバー） |
| 電卓 | `12+25%` = 15 のようなパーセント計算。キーや答えをタップすると白く光る。右上で履歴 |
| 天気 | 昼は白・夜は黒の画面。下のバーを指でなぞると24時間先までの天気に切り替わる。︙で7日間と詳細 |
| タイマー | 上下スワイプで分を設定、数字をタップで開始（白く光って白い数字に）/一時停止、長押しでリセット |
| 習慣 | ＋で追加、景色をタップで今日を記録。記録日数で60段階の旅が進む |
| カメラ | 無音（映像の1コマを保存）。上のダイヤル=明るさ、右のホイール/左下のレンズ=ズーム、右上のスイッチ=前面/背面、A=フィルター |

データはすべて端末のブラウザ内（localStorage / IndexedDB）に保存されます。
